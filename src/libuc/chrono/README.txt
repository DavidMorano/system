CHRONO

This directory contains time related objects and functions.

entity		description
--------------------------------------------------------------------------------

cvtdater	a date converter (limited)
date		a raw date object
dayspec		an object that parses day-of-month-year strings
tmstrs		time strings
tmtime		enhanced broken-out time value management
tmz		convert date-strings to broken-out values
zdb		zone-data-base
zoffparts	zone offset components
zos		zone offset
