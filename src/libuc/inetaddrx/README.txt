INETADDRX

Thses are utility subroutine for managing INET addresses.

--------------------------------------------------------------------------------

inaddrbad		defines a "bad"  INET-4 address
inet4int		convert an INET-4 address into a host 32-bit integer
inetaddr		object that manages a single INET-4 address
inetaddrparse		parse an INET address
inetconv		conversion subroutines
