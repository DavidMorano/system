STROBJ

These (objects in this directories) perform string related operations.
Some of these read strings (sequence of characters), and some of
these write into a string buffer.

name		description
--------------------------------------------------------------------------------

ass		object - reader and parser
asstr1		object - reader and parser
dstr		object - dynamically allocated buffer for strings
strman		object - reader and parser
strmgr		object - writer-builder
strop		object - reader and parser
strstore	object - elaborate string-table builder and access
strtab		object - elaborate strong-table builder
strtabfind	function - read a string-table and return something
