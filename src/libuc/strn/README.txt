STRN

This directory contains the various |strn{x}| subroutines that make
up the famous STR-Counted (STRN) subroutine group.  Among the
subroutines here are the famous |strnwcpy| subroutines.  Thes
esubroutine are given a counted c-string as input and do something
with that, which in-turned results in some return pointer )mostly
to some character within the originally given string).
